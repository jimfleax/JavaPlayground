# Day 6 Assignment

## Assignment 1 — Number Analyzer
Input one positive integer N.

Print:
- number of digits
- sum of digits
- largest digit
- reverse of N
- whether N is palindrome

### Mandatory
Show:
- approach
- dry run
- code
- time complexity
- space complexity

---

## Assignment 2 — Prime Toolkit
Input N.

Print:
1. whether N is prime
2. all prime numbers from 1 to N
3. count of primes from 1 to N

### Thinking requirement
Explain why the prime check can stop at `sqrt(N)`.

---

## Assignment 3 — Pattern Generator
Input rows R.

Print:
```text
*
* *
* * *
...
```

Then print:
```text
1
1 2
1 2 3
...
```

---

## Assignment 4 — Loop Control
Print numbers from 1 to 100:
- skip multiples of 4
- stop completely when a number divisible by 73 is reached

Use both `continue` and `break`.

---

## Assignment 5 — GCD / LCM
Input two positive integers.

Find:
- GCD
- LCM

Do not use library methods for the main solution.

---

## Mandatory Thinking Sheet
For every assignment:
1. What repeats?
2. What is the loop state?
3. Initialization?
4. Condition?
5. Update?
6. What makes it terminate?
7. Boundary cases?
8. Complexity?
