## Debugging
31. Find the bug:
```java
for (int i = 1; i <= 5; i-- ) {
    System.out.println(i);
}
```
32. Find the bug:
```java
int i = 1;
while (i <= 5) {
    System.out.println(i);
}
```
33. What does this print?
```java
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;
    System.out.print(i + " ");
}
```
34. What does this print?
```java
for (int i = 1; i <= 5; i++) {
    if (i == 3) break;
    System.out.print(i + " ");
}
```
