# Day 6 Trainer Tips

1. Teach the loop mental model before syntax.
2. Make students identify initialization, condition and update aloud.
3. Always ask "How many times will this run?" before execution.
4. Use dry-run tables for number/digit problems.
5. Demonstrate an infinite loop intentionally.
6. Demonstrate off-by-one with `<` vs `<=`.
7. Show `break` and `continue` side by side.
8. For nested loops, make students count inner-body executions.
9. Ask students to explain termination, not just output.
10. Connect every loop to a real DSA traversal.
11. Do not let students blindly memorize pattern code.
12. For digit problems, reinforce `% 10` and `/ 10`.
13. Mention overflow when using factorial/powers.
14. Make students test `0`, `1`, smallest valid input and a typical input.
15. Keep a list of the three most common mistakes for Day 7 warm-up.
