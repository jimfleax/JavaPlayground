## Core Mental Model
```text
Repeat a task
     ↓
What must repeat?
     ↓
How many times / until what condition?
     ↓
Initialize state
     ↓
Check condition
     ↓
Execute body
     ↓
Update state
     ↺
Exit when condition becomes false
```

## Loop Selection Rule
- Known/reasonable number of iterations → `for`
- Condition-driven repetition → `while`
- Body must execute at least once → `do-while`
- Stop immediately → `break`
- Skip current iteration → `continue`

## DSA Connection
Loops are the execution engine behind array traversal, searching, sorting, two pointers, sliding window, matrix traversal, hashing passes, simulation and many DP transitions.

## Trainer Outcome
By the end, students should be able to **choose a loop, write it, dry-run it, debug off-by-one errors, handle `break`/`continue`, and calculate basic time complexity**.
