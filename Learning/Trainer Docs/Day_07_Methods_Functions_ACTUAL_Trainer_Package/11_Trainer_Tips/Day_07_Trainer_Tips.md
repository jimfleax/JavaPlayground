# Day 7 Trainer Tips

1. Start with repeated work, not definition.
2. Make students name the task before writing syntax.
3. Always ask input and output first.
4. Show print-vs-return early.
5. Ask students to write the signature before the body.
6. Predict method-call outputs before running.
7. Use method composition to prepare for recursion.
8. Keep each method single-purpose.
9. Use buggy methods for return-path debugging.
10. Ask “Can this logic be reused?”
11. Do not spend too long on advanced object methods today.
12. End with a refactoring challenge.
