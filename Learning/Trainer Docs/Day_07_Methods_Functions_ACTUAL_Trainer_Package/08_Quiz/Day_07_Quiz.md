# Day 7 Quiz — 15 MCQs

1. A method is mainly used to:
A repeat and organize logic B store only strings C replace variables D create loops

4. A method returning no value uses:
A null B empty C void D none

5. Keyword used to send a value back:
A break B return C continue D throw

6. Can a method return an `int` using `return 5;`?
A Yes B No

7. Overloading can differ by:
A parameter list B only return type C method body only D variable names

8. Java passes primitive arguments:
A by reference B by value C randomly D by pointer

9. A local variable is accessible:
A everywhere B only within its scope C only in main D only in class comments

10. `square(5)` for `square(x)=x*x` returns:
A 10 B 20 C 25 D 5

11. A non-void method generally must have:
A a loop B a compatible return on every reachable path C Scanner D switch

12. A method can call another method:
A Yes B No

13. Return value can be stored in a variable:
A Yes B No

14. Changing only return type creates overloading:
A Yes B No

15. `g(f(4))`, f(x)=x+2, g(x)=x*3:
A 12 B 14 C 18 D 20

## Answers
1-A, 2-B, 3-B, 4-C, 5-B, 6-A, 7-A, 8-B, 9-B, 10-C, 11-B, 12-A, 13-A, 14-B, 15-C
