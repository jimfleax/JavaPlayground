# Day 7 Interview Points

1. What is a method?
2. Why use methods?
3. Parameter vs argument.
4. Return vs print.
5. `void` meaning.
6. What is method overloading?
7. Can overloading differ only by return type? No.
8. What is a method signature in Java? Method name + parameter types (for overloading).
9. Why use `static` in beginner examples? To call from static `main` without an object.
10. Is Java pass-by-reference? No; Java passes arguments by value.
11. Can one method call another? Yes.
12. Why should methods be small and focused? Easier testing, reuse and reasoning.

### Strong Answer
“A method is a named block of code that performs a specific task. It can receive parameters and optionally return a value. Methods improve reuse, readability, testing and decomposition.”
