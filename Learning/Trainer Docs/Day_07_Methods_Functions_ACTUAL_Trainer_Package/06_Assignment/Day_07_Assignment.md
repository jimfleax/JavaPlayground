# Day 7 Assignment

## 1. Student Result Utility
Create methods:
- `total(m1,m2,m3,m4,m5)`
- `percentage(total)`
- `grade(percentage)`
- `isPass(percentage)`

## 2. Number Toolkit
Create:
- `isEven`
- `isPrime`
- `reverseNumber`
- `isPalindrome`
- `sumDigits`

## 3. Calculator Using Methods
Create separate methods for add, subtract, multiply, divide and modulo. Handle division by zero.

## 4. Mini Project — Smart Number Analyzer
Input a number and print using separate methods:
- positive/negative/zero
- even/odd
- prime/not prime
- digit count
- reverse
- palindrome/not palindrome

### Mandatory thinking sheet
For every method write:
- Method name
- Inputs / parameters
- Return type
- One-line responsibility
- Dry run
- Complexity
