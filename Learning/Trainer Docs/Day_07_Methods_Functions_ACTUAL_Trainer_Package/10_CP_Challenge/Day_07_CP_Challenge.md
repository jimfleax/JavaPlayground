# Day 7 CP Challenge — Number Analyzer

Input an integer `n`. Using separate methods, print:
1. Number of digits
2. Sum of digits
3. Reverse
4. Palindrome or not
5. Prime or not
6. Even or odd

### Rules
- Do not put all logic inside `main`.
- Use at least 5 methods.
- Each method should have one responsibility.

### Bonus
Create `gcd(a,b)` and `lcm(a,b)` methods and analyze two input numbers.

### Trainer Test Cases
`0`, `7`, `10`, `121`, `12321`, `100`, `-121`, `29`, `30`.
