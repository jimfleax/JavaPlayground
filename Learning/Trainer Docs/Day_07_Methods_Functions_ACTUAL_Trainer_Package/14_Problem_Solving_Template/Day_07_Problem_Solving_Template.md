# Day 7 Method Problem-Solving Template

1. Identify the task.
2. Give the task a meaningful method name.
3. List inputs.
4. Decide output.
5. Choose parameter types.
6. Choose return type.
7. Write method signature.
8. Write logic.
9. Call method from `main`.
10. Dry run one normal and one edge case.
11. Check complexity.
12. Ask whether the method can be reused/composed.

### Example
Problem: check whether a number is even.
- Name: `isEven`
- Input: `int n`
- Output: boolean
- Signature: `static boolean isEven(int n)`
- Logic: `n % 2 == 0`
- Complexity: O(1) time, O(1) extra space.
