# Day 7 — One-Page Recap

## Method
```java
static returnType methodName(parameters) {
    // logic
    return value;
}
```

## Example
```java
static int add(int a, int b) {
    return a + b;
}
int ans = add(10, 20);
```

## Remember
- Parameter = variable in method definition.
- Argument = actual value passed during call.
- `void` = no return value.
- `return` sends value back.
- Print and return are different.
- Methods should have one clear responsibility.
- Overloading = same name + different parameter list.
- Return type alone cannot overload.
- Java is pass-by-value.

## Problem-Solving Rule
**Name → Inputs → Output → Signature → Logic → Call → Test**
