# Java Basic Syntax

Every line of code that runs in Java must be inside a `class`. A class should always start with an uppercase first letter.

```java
public class Main {
  public static void main(String[] args) {
    System.out.println("Hello World");
  }
}
```

## The `main` Method
The `main()` method is required and you will see it in every Java program. Any code inside the `main()` method will be executed.

## System.out.println()
We use `System.out.println()` to print text to the screen.
- `print()`: Prints text without moving to a new line.
- `println()`: Prints text and moves the cursor to the next line.
